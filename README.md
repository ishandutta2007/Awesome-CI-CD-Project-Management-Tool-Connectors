# Top CI/CD & Project Management Tool Connectors Ecosystem

**Curated List of SaaS Products & Open-Source GitHub Projects**  
*Focused on Workflow Automation, Marketplace Integrations & Cross-Platform Tool Connectivity*  
**Last updated: March 2026**

This repository tracks notable **SaaS platforms** and **open-source projects** for **CI/CD & Project Management Tool Connectors**. These tools help teams bridge the gap between development pipelines and project management systems—enabling automated issue creation, build status synchronization, deployment notifications, and cross-tool workflow orchestration without custom glue code.

**Examples** include BrowserStack Third-Party Integrations, Zapier, Make, GitHub Marketplace, Atlassian Marketplace, Slack App Directory, Microsoft Teams Store, Jira Plugins, Jenkins Plugins, Azure DevOps Extensions, and GitLab Integrations (the category leaders).

**Open-source emphasis**: This section highlights every major active project for self-hosted integration platforms, open-source connector frameworks, and community-maintained plugins—ideal for DevOps engineers, platform teams, and developers building transparent, vendor-neutral automation without per-task cloud billing.

Contributions welcome! Open an PR to add/update entries. Keep descriptions factual and link to official sites.

## SaaS/Hosted Platforms

| Product | Description | Pricing (Starting) | Free Tier / Trial Limits |
|---------|-------------|-------------------|--------------------------|
| **[BrowserStack Third-Party Integrations](https://www.browserstack.com/)** | 150+ seamless integrations connecting BrowserStack with CI/CD pipelines (Jenkins, GitHub Actions, Azure Pipelines, CircleCI, Bamboo, Bitbucket, GitLab, TeamCity, Travis CI), issue trackers (Jira, Trello, Asana, GitHub Issues, Slack), and communication tools. Enables automatic test result reporting and one-click bug reproduction . | BrowserStack subscription required (Automate Desktop from ~$12.50/month equivalent on annual plans)  | Free trial on signup; open-source projects eligible for lifetime free BrowserStack access  |
| **[Zapier](https://zapier.com/)** | No-code automation platform connecting 7,000+ apps via triggers and actions. Free tier limited to two-step Zaps (one trigger, one action); Professional unlocks multi-step workflows, filters, paths, and premium apps. Every new account gets a 14-day Professional trial with 1,000 tasks and first 30 steps . | Professional: $19.99/month (750 tasks)  | Free forever: 100 tasks/month, 2-step Zaps only, 15-minute polling, no premium apps, no email support; 14-day Pro trial: 1,000 tasks  |
| **[Make](https://www.make.com/)** | Visual automation platform with 3,000+ app connectors, AI Agents (beta), custom code execution, and scenario templates. Free tier allows 2 active scenarios with 15-minute minimum intervals and 1,000 credits/month . | Core: ~$9/month (10,000 credits, annual billing)  | Free forever: 1,000 credits/month, 2 active scenarios, 15-min minimum interval, 5-minute max execution, 7-day logs  |
| **[GitHub Marketplace](https://github.com/marketplace)** | Official app marketplace within GitHub for Actions, Apps, and Integrations. Revenue share: 5% retained by GitHub for transactions after January 1, 2021 (down from 25%) . Actions can be published free or paid; verified creators get marketplace placement. | Free to browse/install; app pricing set by publishers  | Free to use marketplace; paid apps require separate subscription  |
| **[Atlassian Marketplace](https://marketplace.atlassian.com/)** | App marketplace for Jira, Confluence, and other Atlassian products with 260,000+ customers. Revenue share changing in 2026: Forge apps at 0% up to $1M lifetime revenue, then 16% (rising to 17% July 2026); Connect apps at 20% (rising to 25% July 2026) . | Free to browse; app pricing set by partners  | Free trials typically offered by individual app vendors (varies) |
| **[Slack App Directory](https://slack.com/apps)** | Official directory of Slack apps for workflow automation, CI/CD notifications, incident management, and project updates. Apps can post build status, create channels for deployments, and trigger pipelines from Slack commands. | Free to browse; app pricing set by developers  | Free Slack workspace available; paid app subscriptions vary  |
| **[Microsoft Teams Store](https://learn.microsoft.com/en-us/microsoftteams/platform/)** | App store for Microsoft Teams with integrations for Azure DevOps, Jira, GitHub, Jenkins, and custom connectors. Enables pipeline notifications, approval workflows, and tab-based dashboards within Teams. | Free to browse; app pricing varies  | Free Teams tier available; paid apps vary |
| **[Jira Plugins (Atlassian Marketplace)](https://marketplace.atlassian.com/)** | Ecosystem of 5,000+ plugins extending Jira for CI/CD visibility, test management, time tracking, and deployment tracking. Popular integrations include Jenkins, GitHub, GitLab, Bitbucket, and Azure DevOps connectors. | Free to browse; plugin pricing varies ($0 to enterprise)  | Many plugins offer 30-day free trials; some are free forever |
| **[Jenkins Plugins](https://plugins.jenkins.io/)** | 1,800+ community-maintained plugins covering SCM, build tools, cloud providers, testing frameworks, and notification systems. Core to Jenkins' flexibility; plugins are free and open-source. | Free (plugins are open-source)  | N/A — plugins are free software |
| **[Azure DevOps Extensions](https://marketplace.visualstudio.com/azuredevops)** | Marketplace extensions for Azure DevOps covering CI/CD integrations (BrowserStack, Sauce Labs, Slack, Teams), code quality (SonarQube), and project management connectors. | Free to browse; extension pricing varies  | Free extensions and paid extensions available |
| **[GitLab Integrations](https://docs.gitlab.com/ee/integration/)** | Native integrations built into GitLab for Jira, Slack, Microsoft Teams, Mattermost, Bugzilla, Redmine, Pivotal Tracker, and CI/CD tools. Configured via project settings without third-party marketplace. | Included with GitLab subscription  | Free tier includes basic integrations; Premium/Ultimate add advanced features  |
